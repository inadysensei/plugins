# aws-security-hub

AWSのSecurity Hubの指摘事項をトリアージ、対応する手順を提供します。

## 導入（Cursor）

1. **Settings**の**Plugins**を開く。
2. `+Add`を押す。
3. **From GitHub Repository**を選び、`https://github.com/inadysensei/plugins`を貼る。
4. `aws-security-hub`を検索して`Add`を押す。

## 導入（skillsコマンド）

次を実行します。

```bash
npx skills add inadysensei/plugins
```
