# 現状を調べる

失敗の理由、リソースの所在、基準の有効状態を、読み取りだけで答えます。IaCやfindingは変えません。

## 手順

1. 質問を1文で言い直す。言い直しが依頼と違っていれば、読み取りの前に直す。
2. 失敗一覧が無ければ`read-findings`を先に開く。コントロールが指定されていれば、そのIDだけに絞る。
3. 答えに使う文は、APIのフィールドか、開いた是正URLの文に紐づける。どちらにも無い説明は書かない。
4. 是正の準備と、抑制理由の作成には進まない。依頼が現状の確認だけだからである。

## 返信

言い直した質問、見たフィールド、答え、まだ変えていないことを書きます。
