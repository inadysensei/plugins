# 是正を準備する

是正と判断したものについてIaCのPull Requestを作成します。

## Step 1: リソースの所在を確認する

指摘されているリソースがどこで定義されているかを確認します。
ない場合はimportすることをまずは検討します。

## Step 2: 修正案を検討する

同様のリソースがどのように定義されているかを確認しつつ、修正案を検討します。
次のようなフォーマットで提案します。

```markdown
# 是正提案

## 案1: {タイトル}

{説明}

## 案2: {タイトル}

{説明}
```

推奨する順に案を並べます。

## Step 3: 実装を開始する

ユーザーと同意した案について、Cloud Agentを立てて実装を開始します。
