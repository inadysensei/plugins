# 兆候

すべての群を見ます。見つけた兆候を、場所つきで書き留めます。各行は、兆候とその直し方です。

## 面と色

- 背景、カード、ボタン、アクティブなナビ項目の、紫から青、または紫からピンクのグラデーション → 無彩色の面を1つにし、意味のある場所だけアクセントにする
- 見出し、数字、ロゴのグラデーション文字 → 主の文字色の無地にする
- 色付きの発光。`shadow-[0_0_20px_rgba(139,92,246,0.5)]`、絵文字の`drop-shadow`、光るカプセル → 消し、奥行きは面の段と極細の線で作る
- 内容の背後の放射状の色のにじみや、ぼかした塊 → 消す
- ネオン、または高コントラストの色付き境界 → 不透明度6%から10%の極細の線にする
- 文字に、同じ色相のほぼ同じ色味がたくさんある。ラベンダーが5つなど → 無彩色のランプ1つから、文字の役割を3つにする
- すべての要素が強調され、何も立たない → 画面ごとに、アクセントを1回か2回だけ使う
- 白い内側のハイライトと色付きの影を持つガラスのカード → 極細の線つきの、平らな浮いた面にする

## 文字

- 太さ800か900の見出し → 400から500にし、階層はサイズで作る
- 広い字間の大文字ラベル。`NAVIGATION`や`PAID THIS MONTH` → 通常か、わずかに開いた字間の、文頭だけ大文字にする
- 和文ラベルの字間空け。`letter-spacing`で広げた`ナビゲーション` → 字間0の通常の日本語にする
- 1つの画面にサイズと太さが多すぎる → スケールから少数のサイズにし、太さは400と500にする
- 形式の混ざった数字。`$48,210`の隣の`$124,860.40`や、`07` → 形式を1つにし、等幅の数字にする
- 円の小数、または円の画面の`$` → `¥48,210`か`4,821円`に揃え、小数を付けない
- 小さい文字の負の字間 → 0か、欧文だけわずかに正にする
- 和文を含む行の`letter-spacing`が0でない → 0にする。かなと約物の空きは`palt`で詰める。かなの字幅も変わる
- 強調の斜体、または和文への`font-style: italic` → 色か太さにする。漢字が傾くためである
- 複数行の和文で`line-height`が1.5未満 → 1.7から1.8にする
- 12px未満の和文 → 12px以上にする。本文は14px以上にする
- 1行が40字を大きく超える和文 → およそ25字から40字に収める
- 和文の見出しが欧文のセリフだけを指定し、和文は別のゴシックに落ちている → 和文の書体を選ぶ
- ボタン、ラベル、ナビの明朝 → 大きい見出しだけに戻す
- 和文のWebフォントを、太さの数だけ全部読んでいる → アプリはシステムのゴシックにする。読むなら太さは2つまでにする

## アイコン

- ナビ、ラベルの装飾、状態としての絵文字。家、受信箱、ロケット、お金、警告、上昇、火、しかめ面 → 線アイコンのセット1つか、無しにする
- カプセルと件数の中の絵文字。`18 👤` → ただの数字にする
- アイコンのサイズと色がバラバラ → サイズ1つ、線幅1つ、文字の役割の色にする
- 列からずれたアイコン → すべての行で、アイコンの箱の幅を同じにする
- 何でもAIを示す、きらめきの絵文字 → 消す。何かを説明する場所だけ、無地のアイコンにする
- アイコン代わりの全角記号。`★`や`●` → 線アイコンか、小さい状態の点にする

## 余白

- 任意の値。`mt-[13px]`、`ml-[7px]`、`h-[31px]` → 4pxの段にする
- 1つのリストの中で、行の高さや間隔が違う → 高さを1つ、間隔を1つにする
- 自分の項目より、隣のグループに近いグループ → グループの中を狭く、間を広くする
- 兄弟のカードの中のパディングが不揃い → パディングを1つにする
- 節の上に大きい空きがあり、下は窮屈 → リズムを釣り合わせる

## 文言

文章の文体は見ません。画面に出る形だけを見ます。

- 挨拶の見出し。`おかえりなさい`や`ようこそ` → 題はページ名か期間にする。例は`2026年10月`
- 感嘆符と`!!`。半角と全角の両方を含む → 平叙にする
- 比べる相手の無い変化。`+12%`や`3 less`に感嘆符が付く → `前月比+12%`、`前月より3件少ない`
- 長いプレースホルダ。`何でも検索...`や`キーワードを入力してください` → `検索`
- ラベルとボタンの末尾の句点 → 付けない
- 全角英数字と全角の`％` → 半角の英数字と`%`にする
- 半角カナ → 全角カナにする
- `October 2026`や、月、日、年の順 → `2026年10月`か`2026/10/11`にする
- `...`と`。。。`の混在 → 省略は`…`に揃える。プレースホルダの末尾には付けない
- 画面の数字が偽物に見える。`$123,456`や`[X]` → ありそうな数値にする

## 部品

- 件数、プラン、ショートカット、状態の光るカプセル → 静かな等幅の文字か、キーキャップにする
- 至る所の`PRO`、きらめき付きの`New`、ロケット付きの`Beta`、`新着`、`ベータ` → 消すか、静かな文字のバッジ1つにする
- 検索、ボタン、カードのすべてがカプセル型 → サイズごとの半径を使い、内側の角丸を計算する
- 虹色の棒、光る棒、カプセル型の棒、大文字の曜日ラベルを持つチャート → 系列は1つか2つにし、控えめなグリッドと等幅のラベル、強調色は1つにする
- すべてのチャートや積み上げを、アクセントの数階調だけで描き、リードが無い → 無彩色の段にし、重要な1つだけアクセントにする
- すべての統計カードに足したスパークライン、集計、小さい棒 → 数字、そのラベル、その変化にする
- 同じチャートやレイアウトを持つ、等しいカードの横並び → 主チャート1つ、密な統計、変えた幅にする
- きらめきつきのグラデーションタイルと、グラデーションのワードマークのロゴ → 文字としての製品名に、単純で平らな印を足す
- 艶のある球、グラデーションの球、光る点のロゴ印 → 1色の平らな字形か、ワードマークだけにする

## ランディングとヒーロー

- 見出しの上のカプセルのバッジ。`Introducing X 2.0`や`新登場`に、きらめきの絵文字が付く → 消す。本物の知らせなら、静かな文字リンクにする
- 見出しのグラデーションやシマー → 無地の文字にする
- ヒーローの背後に浮く塊、球体、格子、光る線 → 無地の背景か、本物の製品のビジュアル1つにする
- 見出し、文章、ボタン、下の絵を、すべて縦に積んで中央に揃える → 非対称の分割か、大きい製品プレビューの上の文字にする。レイアウトのパスを見る
- ボタンが3つ以上、またはボタンの下に積んだチップとアバター → 主操作は1つ、従は多くて1つにする
- ボタンの下に積んだ、アバターの点の列や星5つ → 消す
- パララックスと、スクロールで浮く要素 → 静的なレイアウトにし、動きは目的があるときだけにする
- 絵文字と太い題を持つ機能カード → 機能を減らし、線アイコンか無しにする

## ビジュアル

- ヒーローの、艶のある3Dの塊、球体、液体のクローム、紫の星雲 → 製品自身か、働きを表す具体的な比喩1つにする
- 何でもAIを表す、汎用素材のロボット、光る脳、回路の線、ホログラム → 消すか、AIが実際に作るものを見せる
- 画像に焼き込んだ文字、偽のボタン、偽のロゴ → ページの本物の文字と、文字の無いきれいな画像にする
- ページに溶け込まない画像。硬い端と、違う黒 → 背景をページに合わせ、端は柔らかいマスクにする
- すべての節のビジュアル → 助けになる1箇所へ限る。多くの場合、ヒーローだけである

## 動き

- 生きていないものへの`animate-pulse`、`animate-ping`、呼吸する発光 → 静止にする
- カードとボタンの`transition-all`と`hover:scale` → ホバーは色か面の段にし、押下はごく小さい縮小にする
- 単純なUIの弾むスプリングと行き過ぎ → イーズアウトの曲線を1本にする
- 読み込み時に、全部が別の方向から飛んでくる → 短いフェードと上昇を1つにし、小さい時間差を付ける
- パララックス、浮くループ、スクロールで動く要素 → 静的なレイアウトにする
- 幅、高さ、top、leftのアニメーション → 変形と不透明度にする

## テンプレートの見た目

これらはAIっぽさそのものではありません。誰も決めなかったときに、整えた画面が戻りつく姿です。パスのあとで見ます。

- 純灰の`#161616`、Inter、白い文字、古いブランド色のボタン1つ。世界が暖かいか明るい製品なのに、そうなっている → 世界へ寄せたランプと、そこから取ったアクセントにする
- 名前を替えれば別の製品にも当てはまる見出し → この製品がすることを、その製品の名詞で書く
- 空の箱か、汎用の絵であるヒーロー → コードの製品プレビューか、世界から来た画像にする
- すべての製品が同じレイアウト、書体、パレット → 方向に選ばせる
- 和文の画面なのに、欧文だけの書体と、欧文向けの行間1.4のまま → システムのゴシックと、本文1.7から1.8の行間にする
