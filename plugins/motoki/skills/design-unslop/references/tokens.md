# トークン

各パスの開始値です。プロジェクトに良い体系があるなら、その値を残し、使い方だけ直します。これは開始点であり、全製品共通の型ではありません。方向に合わせて動かします。

## 余白のスケール

4、8、12、16、20、24、32、40、48、64、80、96、128

- コントロールの中: 4から12
- 関係する項目の間。リストの行など: 2から8
- グループの間。ラベルとそのリスト、またはカード2つ: 12から24
- 節の間: 32から64。ランディングの節は80から128
- 行の高さ: 密は32、通常は36、タッチは40から44
- ヒーロー: デスクトップではナビから見出しまで96から128。モバイルでは48から64

## アプリのレイアウト

- サイドバーの幅は240から280にする。内容は流動にし、ページのパディングは24から32、上限はおよそ1440から1600にする。
- 上部のバーかページヘッダーの高さは56から64にする。
- ナビの行は32から36、間隔は2から4にする。節のラベルは上24、下8にする。
- 行の中の統計カードは高さを1つにする。デスクトップでは、1行に密なカードを3つか4つ置く。中身は数字だけにする。
- 主チャートは内容の幅の少なくとも3分の2にし、高さは280から360にする。隣の2つ目のデータはリストか表にし、より狭くする。もう1つのチャートにしない。

## 無彩色のランプ

アプリとダッシュボードのすべての面には、グラファイトか、同じくらい灰色のランプを使います。ランディングは、方向の世界の色味に合うランプを選びます。ウォームは紙、木、食べ物、手仕事、人の近くに合います。インクは夜、空、水、技術的なものに合います。自分のランプを同じやり方で色味づけしてよいです。彩度はごく低く保ちます。面が、単体では色に見えません。

| --- | --- | --- | --- |

| ページの背景 | #141415 | #161513 | #0b0d14 |

| 主の文字 | #ededed | #efe9de | #eef0f5 |
| 従の文字 | #a1a1a6 | #aaa398 | #a3a9b8 |
| 控えめな文字とアイコン | #85858b | #8a847a | #7a8296 |

控えめな文字は、メタとキャプションだけに使います。本文は主か従を使います。表の控えめ色は、浮いた面で4.5対1を下回ることがあります。その面では1段暗い色を使います。

意味の色は、どのランプにも収まるよう彩度を落とします。正はダークで`#4cc38a`、ライトで`#16a34a`です。負はダークで`#e5484d`、ライトで`#dc2626`です。

## アクセント

- 本物のブランド色は残す。紫から青へ、または色相から別の色相への発光グラデーションは、AIっぽさである。ブランド色ではない。ユーザーがそう言うときを除く。
- ブランド色が無いなら、世界から取る。暖かい世界には琥珀、珊瑚、残り火のオレンジが合う。冷たい世界にはコバルト、青緑、澄んだ空の青が合う。自然の世界には苔かセージが合う。ブランドが本当に紫でない限り、紫から青の族は避ける。
- アクセントの上の文字は、コントラストを4.5対1以上にする。足りないなら、アクセントを暗くするか、暗い文字を使う。
- アクセントが占めるのは画面の数パーセントにする。主操作、選択、重要な数字1つである。

## ボタン

- ヒーローのボタンの高さは44から48、ナビのボタンは32から36にする。左右のパディングは16から20にする。
- ダークの主ボタンは、ランプのオフホワイトに暗い文字か、アクセントにする。ライトの主ボタンは、主の文字色を塗りに白い文字か、アクセントにする。
- 従ボタンは、極細の線つきの浮いた面と、主の文字にする。
- ダークのボタンの、`inset 0 1px 0 rgba(255,255,255,0.12)`のような柔らかい上端のハイライトは、発光なしで奥行きを付ける。

## 書体

方向の性格で選びます。アプリとダッシュボードは、システムのゴシックを使います。何時間も見るためです。Webフォントは読みません。ランディングで、性格が書体に依存するときだけ、和文の書体を1つ読みます。太さは400と500の2つまでです。

和文を持たない欧文フォントだけを指定しません。Interだけの指定では、和文が端末ごとのゴシックに落ちます。誰も選んでいないInterは、下のシステムのゴシックに替えます。本物のブランド書体は残します。

欧文の書体を先頭に置くのは、`@font-face`で実際に読むときだけです。読んでいない名前を書くと、その書体が入っている端末だけ見た目が変わります。対になる組は、IBM Plex SansとIBM Plex Sans JP、またはNoto SansとNoto Sans JPです。

完全なNoto Sans JPを自分で配ると、太さ1つで数MBになります。サブセットにするか、`unicode-range`で分割された配信を使います。`font-display: swap`にします。太さを7つ読まないでください。

游ゴシックのRegularは、画面では細すぎます。`Yu Gothic Medium`を家族名に書くと太さが固定され、`font-weight`が効きません。`Yu Gothic UI`を游ゴシックより先に書きます。BIZ UDPGothicは画面向けのユニバーサルデザイン書体で、Windows 10の2018年秋以降に入っています。小さい字で読みやすいことが多いです。ヒラギノと游ゴシックUIとBIZ UDPGothicが無いとき、メイリオを予備にします。

明朝は、編集、文芸、手仕事の性格の、大きい見出しだけに使います。画面の長文には使いません。ボタン、ラベル、ナビにも使いません。システムの明朝は`Hiragino Mincho ProN`と`Yu Mincho`です。Webフォントの太さは1つです。Shippori MinchoかNoto Serif JPです。和文の見出しに欧文のセリフだけを指定しません。和文がゴシックへ落ち、混植が事故になります。

ヒラギノ角ゴのW3は400に近く、W5は500に近く、W6は600に近いです。W7以上は使いません。

アプリとダッシュボードの基本は、次の積みです。

```css
font-family:
  "Hiragino Sans",
  "Hiragino Kaku Gothic ProN",
  "BIZ UDPGothic",
  "Yu Gothic UI",
  "Yu Gothic",
  Meiryo,
  "Noto Sans JP",
  sans-serif;
```

欧文を読むときだけ、その書体を先頭に足します。

```css
font-family:
  "IBM Plex Sans",
  "Hiragino Sans",
  "Hiragino Kaku Gothic ProN",
  "BIZ UDPGothic",
  "Yu Gothic UI",
  Meiryo,
  "Noto Sans JP",
  sans-serif;
```

| 性格 | 画面の書体 | 足してよい相手 |
| --- | --- | --- |
| 精密、技術的、落ち着いている | 上のシステムのゴシック | 読むときだけ、欧文にIBM Plex SansかGeist。数字とメタにIBM Plex MonoかJetBrains Mono |
| 暖かい、親しみ、人に近い | 同じシステムのゴシック。ランディングだけ、太さ2つのBIZ UDPGothicかNoto Sans JP | 大きい見出しだけ明朝。游明朝、ヒラギノ明朝、Shippori Mincho |
| 編集、文芸、手仕事 | 画面はゴシック。大きい見出しだけ明朝 | ボタンとラベルはゴシックのまま |
| 遊び、力強い | システムのゴシックが基本。欧文のディスプレイ書体は欧文の部分だけ | 和文の見出しを、欧文ディスプレイ書体のフォールバックにしない |

ディスプレイ用のセリフは、大きい見出しだけに属します。ラベルやボタンには使いません。

## 文字のスケール

和文は全角の正方形です。欧文向けの見出し56pxから72pxを、長い和文へ掛けません。和文のヒーローは、1行およそ12字から20字で収めます。

| 用途 | サイズ | 行間 | 太さ |
| --- | --- | --- | --- |
| 小さいラベル、メタ、件数 | 12から13 | 1.5 | 400。等幅でよい。和文は12未満にしない |
| 従の文字、キャプション | 13から14 | 1.6 | 400 |
| 本文、ナビの項目 | 14から16 | 1行は1.5。複数文の段落は1.7から1.8 | 400から500 |
| ロゴのワードマーク | 16から18 | 1.2 | 500から600 |
| ヒーローの補足 | 16から18 | 1.7 | 400。従の色。幅は全角32字から40字 |
| カードの数値 | 28から32 | 1.2 | 500。等幅。数字なので和文の行間は掛けない |
| ページの題 | 24から32 | 1.45 | 400から500。短いときだけ36 |
| 和文のヒーロー見出し | デスクトップ40から56。モバイル28から36 | 1.4から1.5 | 400から500 |
| 和文が混ざらない短い欧文の見出し | デスクトップ56から72。モバイル36から44 | 1.02から1.08 | 400から500 |

和文の`letter-spacing`は0です。負の値で字間を詰めません。かなと約物の全角の空きを詰めるときは、`palt`を使います。`font-feature-settings: "palt"`です。`palt`は、かなの字幅をプロポーショナルにします。12pxのラベルで字が潰れるなら、そのラベルでは`palt`を外します。和文が混ざらない欧文で、40px以上は`-0.02em`まで詰めます。56px以上は`-0.03em`まで詰めます。和文が1字でも混ざる行は0のままです。

本文と見出しには`font-synthesis: none`と`line-break: strict`を付けます。ラベルと数値には`text-autospace`を掛けません。対応するブラウザでは、本文の段落だけ`text-autospace: normal`を使ってよいです。未対応のブラウザがあるので、ラベルの見た目はこれに頼りません。

## 角丸

| 要素 | 半径 |
| --- | --- |
| キーキャップ、タグ、小さいボタン | 4から6 |
| 行、入力、ボタン | 8から10 |
| カード | 12から16 |
| パネルや窓 | 14から20 |

内側の角丸は、外側からパディングを引いた値です。4未満にはしません。16pxのカードでパディングが8pxなら、中の半径は8pxです。

## アイコン

lucideです。16pxか18px、線幅1.5、色は控えめか従の文字の役割、ラベルまでの間隔は8pxから10pxです。

## 奥行き

- ダーク: 面の段に極細の線を足す。アクティブな行は、上端のハイライトとして`inset 0 1px 0 rgba(255,255,255,0.12)`を持ってよい。
- ライト: 小さいものには`0 1px 2px rgba(0,0,0,0.05)`、浮くものには`0 8px 24px rgba(0,0,0,0.06)`を使う。

## 動き

すべてのイージングは1本にします。`cubic-bezier(0.22, 1, 0.36, 1)`です。

| 用途 | 長さ |
| --- | --- |
| ホバー、押下、切り替え | 120から180ms |
| メニュー、ポップオーバー、ツールチップ | 160から220ms |
| 登場、シート、レイアウトの変化 | 300から500ms |
| 項目の時間差 | 40から60ms。多くて6項目 |

- 登場の上昇は6pxから12pxにする。押下の縮尺は0.97から0.98にする。
- トランジションするのは、色、背景、境界、不透明度、変形だけにする。
