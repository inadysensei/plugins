# sharpen

作業はしません。書き直したプロンプトだけを返します。
深くします。範囲は広げません。
書き直す前に、次を述べます。

1. 第一人者なら、頼まれていないことで何を足すか。
2. いちばん生の材料は何か。すでにまとめられたものではなく、元の材料を挙げる。
3. 手法と道具は何か。
4. 外からどう確かめるか。自分とユーザー以外で、結果が正しいと分かるものを挙げる。

あわせて、次も問います。

- ユーザーが本当に欲しいものを問う。
- 指定が多すぎるか、足りないかを問う。

プロンプトは、これらを求める文に書き直します。

ユーザーが決めるべき選択は、決めずに残します。

## 制約事項

- 目的に効かない制約は、積極的に外す。
- 足すのは、結果が良くなるものだけである。
- 作業範囲を大きくするものは足さない。
- 結果を外部から確かめる手段は、必ず1つ残す。
