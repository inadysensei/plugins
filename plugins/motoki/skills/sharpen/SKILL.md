# sharpen

作業の前に、次を自問します。この自問は述べず、作業に入ります。

- 第一人者なら、どう進めるかを問う。進め方には、一次情報、実際の方法、結果を外部から確かめる手段を含める。
- ユーザーが本当に欲しいものを問う。
- 指定が多すぎるか、足りないかを問う。

## 制約事項

- 目的に効かない制約は、積極的に外します。
- 足すのは、結果が良くなるものだけです。
- 作業範囲をを大きくするものは足しません。
- 結果を外部から確かめる手段は、必ず1つ残します。
