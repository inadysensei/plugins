# AWS

## データ源

Cost ExplorerのUnblendedを使います。
確定した先月と、今月の累計を取ります。
Savings Plansとリザーブドインスタンスは、利用率とカバレッジを見ます。

コストは、画面の転記よりAPIかCLIを先に使います。
認証情報が切れているときは、判定を保留します。

## 予算の読み方

今月の累計と、1日あたりのペースから、月末の着地を見ます。

## 内訳の軸

サービス別とアカウント別です。

## 異常と誤認しやすいノイズ

次は、異常にしません。

- 月の初めにまとめて載る計上
- 反映の遅れ

提案は、コスト削減効果があるものに限ります。
