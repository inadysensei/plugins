# Cursor

見るのは、席の料金と従量です。

## データ源

管理APIで、請求サイクルの支出と利用率を取ります。

## 予算の読み方

着地の見込みは、定額と従量を分けて出します。
従量は、これまでのペースで請求サイクルの終わりまで延ばします。
割合は、見込みを予算で割った値です。

予算の合計は、メモリやルーチンが指す予算表から読みます。

## 内訳の軸

軸は、席種とメンバーと従量課金です。

## アカウント削除候補の提案

利用ログと照らして、削除の候補と、下位プランへのダウングレード候補を出します。

## アップグレードの提案

利用ログと照らして、アップグレードすることでむしろ従量課金を節約できる候補を出します。
