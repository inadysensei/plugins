# notion-style

Notionページを作成、更新するときに設定するスタイル。

## Step 1: 対象

作成または更新するNotionページの本文に適用します。
他人が書いたページは、スタイルの調整を頼まれたときだけ対象にします。

## Step 2: 見出しの変換

参考となる元のMarkdownがある場合は、次の表で対応させます。

| Markdown | Notion |
| --- | --- |
| H1 | タイトル |
| H2 | H1 |
| H3 | H2 |
| H4 | H3 |
| H5 | H4 |

## Step 3: カラー

- 見出し1: その節を表す絵文字を先頭に付ける。背景は`{color="orange_bg"}`にする。既に絵文字があるときは足さない
- 見出し2: 文字色を`{color="orange"}`にする
- 見出し3: 文字色を`{color="gray"}`にする

### 例
```markdown
# 📌 これは見出し1です {color="orange_bg"}

## これは見出し2です {color="orange"}

### これは見出し3です {color="gray"}

#### これは見出し4です
```

`📌`は例。節の内容に合う絵文字を付けます。全ての節でユニークな絵文字にします。

## Step 4: 確認

適用後に、文言と、画像、動画、ファイル等が変わっていないことを確認します。
