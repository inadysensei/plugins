# stop-ai-slop

言っていることは変えず、AIっぽさだけを削る。
分からないことは本文に書かず、確認事項にする。

## Step 1: 原則の確認

1. 意味の完全保持 — 主張・比重・言い切りの強さ・文の働きを変えない。足さない。分からなければ確認事項。
2. SVOCM — 文脈にある動作主・対象だけ復元する。指示語は指し先が分かるときだけ実名化する。
3. 擬人化だけ直す — 意志・感情を持たせた道具・概念は解体する。客観的な仕組みの主語はそのまま残す。
4. 比喩はふだんの言葉にし、含みは残す — 評価や気持ちの向きは別の平易な語で残す。慣用句は残す。
5. 前置き・否定対比は慎重に — 「重要なのは」は述語へ移す。意味を担う「AではなくB」は肯定化しない。
6. 装飾を削る — 絵文字、文末コロン、em dash、冗長なカッコ、和欧文のあいだの余計な半角空白を除く。太字は1000字あたり2箇所以内、箇条書きは全体の15%を目安にする。
7. 読みの拍 — 平均30–45字、読点は0–2。同一文末が3連続したときだけリズムを調整する。1段落1話題。空の予告文は、その重みを述語に残して中身と統合する。
8. 水増しと比喩の重ね — 出典の無い「専門家は」「一般に」「よく言われる」は削るか、確認事項にする。もちろん、言うまでもなく、間違いなく、は削る。言い切りの強さは変えない。比喩は一文に重ねず、ふだんの言葉にする。

文末の種類（依頼・説明・断定・推量）は元のまま維持する。言い切りを推量に弱めたり、説明を可能表現に変えたりしない。

## Step 2: 文章の書き直し

原則に従って、文章を書き直します。

## Step 3: 結果の出力

```markdown
### 書き直した本文

（推敲した本文）

### 変えたところ

- 元 → 後（理由）。意味が動きやすい変更、つなぎ、補った語だけ。最大5件。なければ「なし」

### 残したAIっぽいところ（必要なときだけ）

- 意味や重みがあるので残した表現と、削るかの確認。なければ見出しごと出さない

### 書き手に確かめたい点（必要なときだけ）

- 判断がつかなかった点
```

## 語例カタログ

修正対応表。文字どおりの用法と、ふだんの慣用句は書き換えない。

| 元 | 自然な日本語 |
| --- | --- |
| 効く | 役に立つ、効果がある |
| 壊れる（データ・仕組み） | おかしくなる、使えなくなる |
| 倒す | 合わせる、選ぶ |
| 溶かす（時間など） | 費やす、かける |
| 潰す | なくす、直す |
| 踏み込む | 詳しく書く、中身に入る |
| 静かに | 気づかないうちに |
| 黙って | 知らないうちに |
| 解像度 | 具体さ、詳しさ |
| 腹落ち | 納得 |
| 重要なのは | 述語へ（〜が重要だ） |
| いかがでしたでしょうか | 削る |

書き換えない例: お握り、氷を溶かす、お腹を壊す。
