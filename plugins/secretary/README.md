# secretary

秘書ボットの定例確認です。
平日の未確認メンションと、見えるチャンネルの`@channel`を、番号付きの報告にします。

## 導入（Cursor）

1. **Settings**の**Plugins**を開く。
2. `+Add`を押す。
3. **From GitHub Repository**を選び、`https://github.com/inadysensei/plugins`を貼る。
4. `secretary`を検索して`Add`を押す。

## 導入（skills コマンド）

次を実行します。

```bash
npx skills add inadysensei/plugins
```
