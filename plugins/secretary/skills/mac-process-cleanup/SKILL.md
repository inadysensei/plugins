# mac-process-cleanup

重い常駐や高負荷のプロセスを整理する手順です。

## Step 1. データを集める

この段階は調査だけです。
まだ何も止めません。消しません。
止める対象と消す対象を、先に分けるためです。

### CPU/メモリ負荷を調べる

CPUとメモリの上位を、次のコマンドで取ります。

```bash
top -l 2 -s 1 -n 20 -o cpu -stats pid,cpu,mem,command
```

2回サンプリングし、2回目の結果を使います。
1回目は、起動直後の値になりやすいためです。
ロード平均と、user、sys、idleの割合も控えます。

### 常駐の出所を調べる

次の場所を見ます。

- ログイン項目: `osascript -e 'tell application "System Events" to get the name of every login item'`
- ユーザーのLaunchAgents: `~/Library/LaunchAgents`
- 全体のLaunchAgents: `/Library/LaunchAgents`
- 全体のLaunchDaemons: `/Library/LaunchDaemons`
- いま動いているGUIとバックグラウンド: System Eventsか`lsappinfo`

Apple純正は候補にしません。サードパーティだけを拾います。

### 分類とID

各候補に、次の接頭辞でIDを振ります。
番号は、接頭辞ごとに1から連番です。
ユーザーがIDだけで指示できるようにするためです。

| 接頭辞 | 意味 |
|--------|------|
| A | 今だけ止める |
| B | 今後起動しない（アプリは残す） |
| C | アプリごと削除する |
| K | 残す（Keep） |

番号の例は`A1`、`A2`、`B1`です。
別の接頭辞は`C1`、`K1`のように、それぞれ1から振ります。

## Step 2. ユーザーに確認する

調査結果だけを出します。
出力は、必ず次の形式にします。

```markdown
## いまの負荷
- ロード平均: …
- CPU: user …% / sys …% / idle …%

## 高負荷プロセス（上位）
| 名前 | PID | CPU% | メモ |
|------|-----|------|------|
| … | … | … | … |

## 常駐候補
### A. 今だけ止められそう
- **A1** 名前 — 理由（1行）
- **A2** …

### B. 今後起動しなくてよさそう（アプリは残す）
- **B1** 名前 — 理由（1行）・対象（LaunchAgent / Daemon / ログイン項目）
- **B2** …

### C. 消してよさそう（アプリごと）
- **C1** 名前 — 理由（1行）・入り方（Homebrew cask / 公式 / 不明）
- **C2** …

### K. 残したほうがよさそう
- **K1** 名前 — 理由（1行）
- **K2** …

## 確認してほしいこと
進め方を ID で指定してください（例: `A1 止める` / `B1 起動しない` / `C1 消す` / `C1 は触らない`）。
C で消す場合、ユーザーデータ置き場も消すか別に教えてください。
```

## Step 3. 作業を開始する

選択が揃ったら、実行の前に計画だけを出します。
この時点では、コマンドを実行しません。
計画の各行にも、同じIDを付けます。

```markdown
## 実行計画
1. **A1** …（操作: 今だけ止める）
2. **B1** …（操作: 起動しない）
3. **C1** …（操作: 削除 / ユーザーデータ: 消す|残す）
```

この計画を承認したあとにだけ、実行します。

### A. 今だけ止める

プロセスを終了します。
アプリと起動設定は残します。
今の負荷だけを下げるためです。

`AppName`は、止めるプロセス名に置き換えます。

```bash
pkill -x "AppName"
# または
osascript -e 'quit app "AppName"'
pgrep -xl "AppName" || echo closed
```

子プロセスが残る開発ツールは、親を終了させます。
必要な子も`killall`します。
親だけでは、負荷が残るためです。

### B. 今後起動しない（アプリは残す）

アプリ本体は残します。
自動起動だけを外します。
多くの場合、管理者権限が必要です。

1. `launchctl bootout`で下ろす
2. 必要なら`launchctl disable`する
3. plistを削除するか、`.disabled`へリネームする
4. PrivilegedHelperToolsのヘルパーがあれば、削除を検討する
5. ログイン項目にあれば、外す

### C. アプリごと消す

アプリ本体と、起動の定義を消します。
ユーザーデータは、段階2で消すと答えたときだけ消します。

1. 公式のアンインストーラか、Uninstallツールがあれば、それを使う
2. Homebrew caskなら、uninstallする
3. ネストしたsudoで失敗したら、管理者のシェルから実体を削除する
4. 次を片付ける
   - アプリ本体
   - Launch定義
   - Application Support
   - Preferences
   - Caches
   - Logs
   - PrivilegedHelperTools
5. 必要なら`pkgutil --forget`する
6. ユーザーデータの置き場は、段階2で消すと答えたときだけ削除する

### 実行後の確認

結果は短く報告します。
報告でもIDを使います。

- **A1**/**B1**/**C1** … 結果（止めた/無効化した/削除した/失敗）
- 対象のプロセス、plist、アプリの有無
- 負荷が下がったかを確認して報告する
